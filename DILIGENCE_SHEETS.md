# Per-name diligence sheets — the 12 convergent winners

One page per name, strict template, trade-ready. Each sheet
distinguishes: what we're betting on (catalyst), what protects us
(floor), what could break it (red flags), how to size (conviction
band), and what to monitor (trigger conditions). These are the
operational counterpart to `CASE_WORKBOOK.md` (which teaches the
framework) and `SYSTEMATIC_RANKINGS.md` (which surfaces the names).

Naming convention: each section uses a fixed seven-field template.

```
TICKER (Name)                         mcap | spot | P/B | drawdown
-------------------------------------------------------------------
CATALYST       What the PSU plan / activity says will create value
FLOOR          What protects the downside
CONVERGENCE    Screens × archetypes won (the consensus evidence)
RED FLAGS      Caution items from plan text
SIZING         Conviction band + recommended position weight
MONITOR        What to watch; cadence
TRIGGERS       Exit / add / re-evaluate conditions
```

## How to use these sheets

1. **Before opening any position**, re-read the relevant TRIGGERS
   block and confirm none of the EXIT conditions have already
   materialised.
2. **Set the MONITOR cadence as calendar reminders.** Quarterly
   prints for fundamental names; weekly insider for behavioral.
3. **Treat the SIZING band as a ceiling, not a target.** Start at
   half-band and add on confirming evidence.
4. **Update the catalyst block** whenever the PSU plan changes
   (annual proxy) — recompute the gap to threshold.
