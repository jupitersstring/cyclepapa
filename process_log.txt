PHASE 4 — SYNTHESIS BUILD-OUT
--------------------------------------------------------------------------------

After fund coverage scaled past 100, individual sheets were no longer
useful for finding asymmetric patterns. Built cross-fund synthesis tabs:

  Cover, Index, All Activity (master table)

  ASYMMETRIC SUMMARY - methodology + flag legend

  CONSENSUS BUYS - tickers held/added by 3+ funds across categories.
                   Heuristic: count of funds touching the ticker positively,
                   max % of portfolio observed in any fund, threshold flags.

  HIGHEST CONVICTION - tickers at >=15% of any single fund's portfolio.
                       Includes hyper-conviction (>=30%) tag.

  ACTIVIST CATALYSTS - tickers with 13D/13G/A filings + active campaign
                       narrative.

  MULTI-FUND NEW INITS - names initiated as new top positions by 2+ funds
                         simultaneously in the window.

  CONVICTION ADDS - captures "add events" from categories (3) new init and
                    (4) material increase across all 250 funds.

  MICRO-CAP CONVICTION ADDS - filtered subset of Conviction Adds excluding
                              mega/large-cap names.

  USER-SUGGESTED WATCHLIST - 239 rows from user's first dump (150+ hidden
                              microcap managers); flagged 'In Workbook?'.

  WATCHLIST V2 WARRANTS+HIDDEN - 173 rows from user's second dump; 50
                                  warrant-related entries highlighted yellow;
                                  160 net-new.

BUILD PIPELINE:
  build_activity_xlsx.py       - ingests research markdowns -> per-fund sheets

    - AMF France (amf-france.org)
    - BaFin Germany (bafin.de)

  Asia:

    - HKEX (Hong Kong)

  Warrant universe:
    - CommonStockWarrants.com (Dudley Baker - primary US+Canada warrant DB)
    - CanadianWarrants.com
    - HKEX Derivative Warrant Database
    - Palisades Gold Radio podcast (for ongoing commentary)

CAVEATS:
  - 13F filings have a 45-day lag from quarter-end.
  - For pod-shop / quant / multi-PM funds (Citadel, Millennium, RenTec,
    Bridgewater), 13F data is largely stale by the time it's filed.
  - Heuristic ticker extraction is imperfect - non-US tickers (esp. Japan
    4-digit codes) may not always parse.
  - "Highest conviction %" numbers reflect SELF-REPORTED weights in 13F or
    factsheet, not implied bets - some funds report only US-equity slices.
  - Activist catalyst flags are heuristic; cross-reference per-fund tabs
    for filing dates and campaign status.

HOW TO RUN A NEW REFRESH
--------------------------------------------------------------------------------

To pull the latest 13D/13G data and add a fresh snapshot to the workbook:

  1. Dispatch a research agent to scan EDGAR for filings in the last N days.
  2. Save output to /tmp/sweep_13d_<window>.md.
  3. Run build_13d_sweep_sheet.py with the new file (modify the ROWS list).
  4. Commit the updated fund_activity_last_6mo.xlsx.

To add a new batch of funds:

  1. Dispatch research agent with the per-fund format template.
  2. Save output to /tmp/research_<group>.md.
  3. Add the file path to MD_FILES in build_activity_xlsx.py and the
     other three build scripts.
  4. Run all four build scripts in sequence:
       build_activity_xlsx.py
       build_synthesis.py
       build_conviction_adds.py
       build_watchlist.py (optional)
  5. Commit and push.

To regenerate the shareable text briefs:

  - asymmetric_setups_2026.txt: written manually after each major workbook
    update; ranking criteria documented in the file itself.
  - sitg_positioning_synthesis.txt: same approach.
