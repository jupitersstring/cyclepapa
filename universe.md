# Universe — Broad Candidate List

The watchlist that feeds the framework. Organized by region → sector →
bucket. Three confidence tiers:

- **★ Confirmed** — recap event documented in this repo or widely reported
- **○ Probable** — recap event known from public reporting; mechanism
  needs verification before scoring
- **▲ Watch** — sector under stress; specific catalyst not yet announced
  but a Tier-S filing is plausible in next 6–12 months

Bucket tags use the §9 framework: **A** = listed common is the trade,
**B** = anchor instrument is the trade, **C** = legacy cancelled, new
common is a separate trade.

> **This is a research watchlist, not investment recommendations.** Many
> names need live verification (current cap stack, fulcrum debt prices,
> Form 4 / SEDI / PDMR / SAST insider activity, latest 13F / TR-1
> changes) before sizing.
