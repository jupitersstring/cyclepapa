# Pre-Recap Watch Register

Names where the *prerequisite* for a Tier-S filing is visible but the
deal itself has not been announced. The screener cannot pick these up
because no event has happened yet — the watch exists precisely because
the universe.md → universe_screen.py loop is reactive.

Updated quarterly. Currently 24 names organized by the trigger that
would convert them from watch → universe row.

## Trigger taxonomy

| Trigger | Description |
|---|---|
| **MAT-WALL** | Maturity wall within 18 months that exceeds liquid resources × 2 |
| **PCA-EXIT** | Regulator-imposed Prompt Corrective Action exit (recap funded) |
| **STRAT-REV** | Strategic-alternatives announcement; banker hired |
| **ANCHOR-IN** | Anchor investor disclosure (13D/G or equivalent) without deal yet |
| **CTC** | Customer/contract loss creates cap-stack stress |
| **POLICY** | Pending regulatory/legislative trigger of mandatory recap |
| **OFFTAKE** | Offtake-anchored deal in negotiation (A2 pipeline) |
| **VOTE** | Shareholder/court vote pending on recap structure |

## Discipline

Each row should carry: (1) a concrete trigger date or window, (2) the
named anchor or sponsor most likely to lead, (3) the kill criteria
that would move the name to `pass`.

Stale entries (no progress on trigger in 6 months) get demoted. Names
that fire convert to a universe.md row + YAML build queue entry.
